# Budget Hotel Site Proposal: Thai Highways

Where to build a budget hotel (800 THB a night or less) on Thailand's trunk highways: Department of Highways traffic counts (fiscal 2568) matched with Booking.com budget-hotel supply at 121 roadside points on highways and secondary roads.

- `index.html` – the whole dashboard in one file (data and chart library included; no server or sign-in needed).
- `data/` – the same data as CSV files: sample points, routes, and the budget hotels found with prices.

Data as of 10 November 2026.
